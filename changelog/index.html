Version 2.0.0 · Current

Free local Markdown rendering and export.

Version 2.0.0 is the current public Chrome Web Store release. It is free to use and has no account, subscription, payment, license key, advertising, or extension analytics.

  • Type or paste Markdown directly in the extension.
  • Upload or drag local .md and .txt files.
  • Export the rendered document as PNG, JPG, or an SVG image container.
  • Copy the generated PNG to the clipboard.
  • Open a full-page preview with an automatic table of contents.
  • Print the full-page preview or save it as PDF through Chrome.
  • Use temporary local preview storage with cleanup for older entries.
