Help

Support

Markdown to Image is free and does not require an account, purchase, subscription, or license key.

Rendering issues

Include the Chrome version, extension version, export format, and a minimal non-sensitive Markdown example. Do not send private documents.

External images

Some remote images cannot be included in an export when their host blocks cross-origin loading. Try downloading the image and embedding it as a data image, or use an image host that allows browser rendering.

Privacy questions

Read the privacy policy for details about local processing, clipboard access, storage, and external image requests.

Contact

Email support. Please do not attach private Markdown files unless you have removed sensitive information.
