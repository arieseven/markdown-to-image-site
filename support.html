Help

Support

Markdown to Image is a free Chrome extension for rendering Markdown locally and exporting PNG, JPG, SVG, or a full-page preview for PDF printing. It does not require an account, purchase, subscription, or license key.

Current release: version 2.0.0. If you have not installed it yet, get it from the Chrome Web Store.

Install or update the extension

Install Markdown to Image from its official Chrome Web Store page. Chrome normally updates installed extensions automatically. If an update appears delayed, open chrome://extensions, enable Developer mode, and select Update.

Rendering and export issues

When reporting a rendering issue, include your Chrome version, extension version, selected export format, and a minimal non-sensitive Markdown example. Do not send private documents.

  • PNG is the best default for copying and general sharing.
  • JPG can produce smaller files for content without transparency.
  • SVG is useful when a scalable output fits the destination workflow.

Full-page preview and PDF

Select Open in Tab to create a focused reading view with an automatic table of contents. Use the Print / Save PDF action or Chrome's print dialog to create a PDF. Browser print settings control margins, headers, footers, and page size.

External images

Some remote images cannot be included in an export when their host blocks cross-origin loading. Try downloading the image and embedding it as a data image, or use an image host that permits browser rendering. The remote image host may receive standard network information when Chrome requests the image.

Clipboard permissions

The extension reads clipboard text only after you choose Paste. It writes a generated PNG only after you choose Copy Image. See the privacy policy for the complete data-handling explanation.

Contact

Email support. Include reproducible steps and remove sensitive information before sharing any Markdown sample.
