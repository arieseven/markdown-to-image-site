Privacy

Privacy Policy

Effective August 1, 2026

This policy explains how the Markdown to Image Chrome extension handles information. The extension is free, has no account system, and does not operate an analytics, advertising, payment, or license service.

Markdown and generated files

Markdown text, uploaded Markdown or text files, rendered HTML, generated images, and full-page preview content are processed locally by the extension. The extension does not upload this content to a developer-operated server.

Clipboard access

The extension reads text from the clipboard only when you choose Paste. It writes a generated image to the clipboard only when you choose Copy Image. Clipboard content is not transmitted to the developer.

Local browser storage

Chrome local storage is used for temporary full-page preview content and basic installation metadata such as the installed extension version and installation/update timestamps. The metadata remains on your device and is not used for analytics. Temporary preview entries older than approximately 24 hours are removed when preview cleanup runs. Removing the extension clears its local storage.

External images and links

If your Markdown contains an externally hosted image, Chrome may request that image from the host you specified so it can be displayed or rendered. That third-party host may receive standard network information such as your IP address. Links are opened only when you choose to follow them. The extension adds a no-referrer policy to rendered images and does not send Markdown content with those requests.

No sale, advertising, or tracking

The developer does not sell user data, use document content for advertising, build user profiles, or track extension activity across websites. The extension does not include third-party analytics.

Limited Use

Information handled by Markdown to Image is used solely to provide local Markdown rendering, preview, clipboard, and export features. It is not transferred to third parties, used for advertising, or made available for human review.

The use of information received from Chrome APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

Contact

For privacy questions, contact support.
